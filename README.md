# 🎨 공모전 원서 도우미

내 정보·약력·작품을 한 번 저장해 두고, 공모전마다 골라서 원서(PDF·사진)를 만드는 휴대폰 웹앱.

- 👤 내 정보: 성명·소속지부·분야·주소·연락처·증명사진, 약력(✓ 고르기·순서 바꾸기)
- 🖼 작품: 작품명·재료·규격·제작년도·사진, 어느 공모전에 냈는지 표시
- 📝 원서: A4 미리보기 → 📄 PDF / 🖼 사진 저장, 💬 카톡·메일로 보내기, 📋 칸별 복사(한글 양식용), 🌐 웹하드 도우미(주소 열기·아이디/비번 복사·올릴 파일 묶음)
- 📋 접수 기록: 접수 완료·입선·특선… 상태, 같은 작품 중복 경고, 마감 알림
- ⚙ 백업: 카톡으로 백업 보내기, 파일 저장/불러오기

모든 자료는 **이 기기(localStorage)에만** 저장됩니다. 서버 없음, 로그인 없음.
