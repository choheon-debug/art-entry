🎨 공모전 원서 도우미

한 번 써 두고, 공모전마다 골라서 내요

👉 앱 열기
🔒 로그인이 없고, 모든 자료는 내 휴대폰에만 저장돼요.

📲 1. 홈 화면에 앱처럼 깔기

🍎 아이폰

  1. 사파리로 열기
  2. 아래 공유(□↑)
  3. 홈 화면에 추가 → 추가

🤖 안드로이드

  1. 크롬으로 열기
  2. 오른쪽 위 ⋮
  3. 홈 화면에 추가 → 추가

카톡에서 링크를 누르면 카톡 안에서 열려요.
아이폰은 오른쪽 아래 나침반, 안드로이드는 오른쪽 위 ⋮ → 다른 브라우저로 열기를 눌러 주세요.

👤 2. 내 정보 (처음 한 번만)

  • 이름·소속지부·분야·주소·휴대폰을 쓰면 바로 저장돼요.
  • 사진 칸을 누르면 증명사진을 넣어요.
  • 약력은 한 줄씩 쓰고 추가. ✓ 표시한 줄만 원서에 들어가요. ▲▼로 순서를 바꿔요.

🖼 3. 작품 넣기

  1. ＋ 작품 추가
  2. 작품명·재료·규격(cm)·제작년도 쓰기
  3. 📷 작품 사진 넣기 → 저장

📝 4. 원서 만들기

  1. 아래 📝 원서 → ＋ 새 원서 만들기
  2. 공모전 이름을 쓰고 작품을 고르면 미리보기에 원서가 나와요.
  3. 📄 PDF 저장 · 🖼 사진으로 저장 · 💬 카톡·메일로 보내기

⚠️ 이미 다른 공모전에 낸 작품을 고르면 알려 줘요.

📋 5. 한글(HWP) 양식을 줄 때

  • 칸별 복사에서 복사 → 한글 파일의 그 칸에 붙여넣기
  • 증명사진·작품사진도 따로 저장할 수 있어요.

🌐 6. 웹하드에 올릴 때

  1. 웹하드 주소·아이디·비밀번호를 한 번 적어 두기
  2. 📦 올릴 파일 한 번에 저장 → 이름_작품명_원서.pdf처럼 저장돼요
  3. 🌐 웹하드 열기
  4. 아이디 복사 · 비밀번호 복사로 로그인
  5. 웹하드에서 올리기 → 방금 저장한 파일 고르기

✅ 7. 접수 기록

  • 원서 아래 접수 상태에서 접수 완료
  • 결과가 나오면 입선·특선으로 바꿔 두기
  • 아래 📋 접수 기록 탭에서 모아 봐요.

💾 8. 백업 (꼭 해 두세요!)

자료가 휴대폰에만 있어서, 휴대폰을 바꾸면 사라질 수 있어요.

  • 오른쪽 위 ⚙ → 💬 카톡으로 백업 보내기 → 나와의 채팅
  • 되살릴 때: 카톡의 백업 파일 저장 → ⚙ → 📂 불러오기
